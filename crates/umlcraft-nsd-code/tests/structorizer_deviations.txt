# Methods whose structure differs from Structorizer's Java import on purpose (docs/nsd-spec.md § 4).
Exceptions.withResources: Structorizer adds a broken "var r: Reader <- null" after the try; we put the resource at the start of the try only
Jumps.labels: Structorizer keeps the label "outer:" as a red, disabled instruction; we leave it out and report it
Loops.endless: while (true) is an endless loop for us, Structorizer keeps a while loop
Loops.free: a for loop with several variables becomes instructions and a while loop, as in Structorizer, but we keep the update at the end of the body, which Structorizer drops (also in for (int i = 0; ; i++))
Misc.check: assert stays an instruction as written; Structorizer turns it into an alternative with a throw
Misc.sync: synchronized puts its body in place with the lock as a comment; Structorizer makes a for loop "for synchronized <- 0 to 0"
Switches.defaultInMiddle: Structorizer misreads a default in the middle as a fourth, empty case
